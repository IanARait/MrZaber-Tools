# To-Do List

A full-featured task management app with drag-and-drop, categories, due dates, and progress tracking.

## Features

- Add, edit, delete tasks
- Drag-and-drop reordering
- Categories (Personal, Work, Shopping, Health)
- Due dates with overdue warnings
- Progress tracker
- Filter by All / Active / Completed
- Search tasks
- Persistent storage (localStorage)
- Responsive design

## How to Use

Open `index.html` in any browser. Add tasks using the input form, drag to reorder, click checkbox to complete.
