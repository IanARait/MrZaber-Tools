# Scientific Calculator

A full-featured scientific calculator with keyboard support, memory functions, and calculation history.

## Features

- Basic arithmetic (+, -, ×, ÷)
- Scientific functions (sin, cos, tan, log, ln, sqrt, factorial, exp)
- Memory operations (MC, MR, M+, M-)
- Keyboard support
- Calculation history panel
- Responsive design

## How to Use

Open `index.html` in any browser. Use mouse clicks or keyboard to input calculations.

### Keyboard Shortcuts

| Key | Action |
|-----|--------|
| `0-9` | Numbers |
| `.` | Decimal point |
| `+`, `-`, `*`, `/` | Operations |
| `Enter` | Equals |
| `Backspace` | Delete last |
| `Escape` | Clear all |
| `(` / `)` | Parentheses |
