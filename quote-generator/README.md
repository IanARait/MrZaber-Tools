# Random Quote Generator

A quote discovery app with categories, favorites, search, and sharing features.

## Features

- 40+ quotes across 8 categories
- Category filter
- Search by text or author
- Favorites (stored in localStorage)
- Copy to clipboard
- Share to X (Twitter)
- Auto-rotate (10-second interval)
- Responsive design

## How to Use

Open `index.html` in any browser. Click "New Quote" for a random quote, filter by category, or search. Use the heart to favorite, the copy button to copy, or the X button to share.
