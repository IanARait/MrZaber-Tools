# Password Generator

A secure password generator with customizable options, strength meter, and password history.

## Features

- Adjustable length (4-64 characters)
- Character type selection (uppercase, lowercase, numbers, symbols)
- Exclude similar characters
- Exclude duplicate characters
- Password strength meter
- Copy to clipboard
- Password history (last 10, stored in localStorage)
- Responsive design

## How to Use

Open `index.html` in any browser. Adjust settings and click "Generate" or let it auto-generate on load.
