# Frontend Developer Portfolio

A professional portfolio showcasing 5 frontend projects built with HTML, CSS, and Vanilla JavaScript.

## Projects

| # | Project | Description |
|---|---------|-------------|
| 1 | [Calculator](/calculator) | Scientific calculator with keyboard support, memory functions, and calculation history |
| 2 | [Weather App](/weather-app) | Real-time weather with 5-day forecast, search history, and °C/°F toggle |
| 3 | [To-Do List](/todo-app) | Task manager with drag & drop, categories, due dates, and progress tracking |
| 4 | [Password Generator](/password-generator) | Secure password generator with strength meter, custom options, and history |
| 5 | [Random Quote Generator](/quote-generator) | Inspirational quotes with categories, favorites, search, and Twitter sharing |

## Features

- Hero section with animated code block
- About section with animated counters
- Skills section with progress bars
- Project cards with hover effects
- Contact form with validation
- Dark mode with system preference detection
- Fully responsive design
- Smooth scroll animations
- SEO-optimized
- Accessible

## Deployment

1. Push to a GitHub repository
2. Go to **Settings > Pages**
3. Select `main` branch and `/ (root)` folder
4. Click **Save**

The portfolio will be live at `https://<your-username>.github.io/<repo-name>/`

Each project can also be opened independently via its own `index.html`.
