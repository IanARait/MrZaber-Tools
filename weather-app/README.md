# Weather App

A real-time weather application displaying current conditions and a 5-day forecast using the OpenWeather API.

## Features

- Current weather (temperature, humidity, wind, pressure)
- 5-day forecast
- Search by city name
- Search history (clickable, stored in localStorage)
- °C / °F toggle
- Dynamic background based on weather
- Responsive design

## API Setup

1. Get a free API key at [OpenWeather](https://openweathermap.org/api)
2. Open `script.js`
3. Replace `YOUR_API_KEY` with your actual API key

Without an API key, the app displays mock data for demo purposes.
